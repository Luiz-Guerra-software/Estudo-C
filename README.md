# Estudo de C

Programas que escrevi enquanto estudo a linguagem C, em ordem de aprendizado. Cada arquivo foca em um tópico.

## Tópicos

| Nº | Arquivo | Tópico |
|----|---------|--------|
| 01 | `01-Codigo Definição de triângulo.c` | Condicionais e operadores lógicos: lê três lados, verifica se formam um triângulo e o classifica como equilátero, isósceles ou escaleno |
| 02 | `02-Codigo Para.c` | Laço `for` |
| 03 | `03-Codigo enquanto.c` | Laço `while` |
| 04 | `04-Codigo fazer enquanto.c` | Laço `do-while` |
| 05 | `05-Codigo matriz.c` | Matrizes |
| 06 | `06-Código struct.c` | Structs |
| 07 | `07-Codigo with 2 strucy.c` | Programa com duas structs |
| 08 | `08-Código Funcão.c` | Funções |
| 09 | `09-Código Ponteiro.c` | Ponteiros |
| 10 | `10-Código Passagem por referência.c` | Passagem de parâmetros por referência |
| 11 | `11-Código alocação dinâmica.c` | Alocação dinâmica de memória |
| 12 | `12-Código ponteiros com vetores e função.c` | Ponteiros com vetores e funções |
| 13 | `13-Código de ponteiro com struct e usando notacao simplificada.c` | Ponteiros com struct e notação simplificada |

## Como compilar e executar

Requisito: compilador GCC.

```bash
gcc nome-do-arquivo.c -o programa
./programa
```

Se o nome do arquivo tiver espaços, coloque-o entre aspas.
